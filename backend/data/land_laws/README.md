# Land-law grounding corpus

Drop **PDF** files here to ground Meridian's answers (reports + chat) in real
Toronto/Ontario property law. This folder is the source corpus for the RAG
pipeline.

## How it flows

```
data/land_laws/*.pdf
  → extract text (pypdf)          app/services/rag/ingest.py
  → chunk (800 words / 100 overlap)
  → embed (local NeMo Retriever, :8081)
  → store vectors (ChromaDB)       data/vector_store  · collection "land_laws"
  → retrieve + rerank (:8082)      app/services/rag/service.py
  → grounded passages → LLM        shown as citations in the chat UI
```

## Add your own

1. Copy any `.pdf` into this folder.
2. Make sure the embedding server is up: `bash scripts/serve_embed.sh` (:8081).
3. Re-index:  `python scripts/ingest_docs.py`  (idempotent — safe to re-run).

The starter PDFs here are generated by `scripts/seed_land_laws.py` (Land Transfer
Tax, Ontario Heritage Act, TRCA flood regulation, property tax & development).
Delete them if you only want your own documents.
